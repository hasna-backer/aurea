# Aurea — Minimal Clinical Skincare (Demo)

Fictional minimal skincare brand landing page. Built as portfolio work to show clean, aesthetic, professional product design.

- **Stack:** Next.js 14 (App Router), Tailwind CSS, GSAP + ScrollTrigger
- **Style:** Sand / olive ink / gold, Cormorant Garamond + Inter
- **Sections:** Hero + floating product card, stat strip, 3-step ritual, product trio, reviews, quiz CTA + footer
- **Images:** Unsplash (free under Unsplash License), credited on-page
- **Data:** All products, reviews, claims are imaginary

## Run locally

```bash
npm install
npm run dev -- -p 3002
```

Open http://localhost:3002

## Deploy on Vercel

Import this repo in Vercel, framework preset Next.js, no extra config needed.
